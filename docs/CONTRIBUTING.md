# Contributing to TradeFlow WebApp

First off, thank you for considering contributing to TradeFlow! 

## Process
1. Fork the repo.
2. Create your feature branch (`git checkout -b feature/amazing-ui-update`).
3. Commit your changes (`git commit -m 'feat: Add amazing UI feature'`).
4. Push to the branch (`git push origin feature/amazing-ui-update`).
5. Open a Pull Request against the `webapp` branch.

## Code Standards
- We strictly enforce TypeScript strict mode for the frontend.
- Ensure Tailwind utility classes follow a clean, consistent ordering.
- For the backend, `mypy` type hinting and `black` formatting are required.
